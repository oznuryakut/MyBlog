# MyBlog

Bu proje, Node.js ve Express kullanılarak geliştirilmiş basit bir blog uygulamasıdır.

## 🚀 Özellikler

- Kullanıcı kayıt / giriş sistemi
- Blog yazısı ekleme
- Blog yazısı silme
- Yorum yapma
- Basit admin yetkilendirme
- RESTful API yapısı

## 🛠️ Kullanılan Teknolojiler

- Node.js
- Express.js
- EJS (veya kullandığın template neyse onu yaz)
- MongoDB / MySQL (hangisini kullanıyorsan)
- HTML, CSS, JavaScript

## 📦 Kurulum

Projeyi çalıştırmak için:

git clone https://github.com/oznuryakut/MyBlog.git
